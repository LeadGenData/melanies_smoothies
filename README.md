## 📋 Overview

A custom web ordering application built to streamline customer smoothie selection, ingredient customization, order submission, and transaction status management.

---

## 🎯 Business Problem

* **Context**: Manual order taking created order customization errors, lost ingredient records, and delayed order fulfillment times during peak hours.
* **Solution**: Developed a clean web interface that records ingredient choices directly into a backend database and confirms orders instantly.

---

## ⚙️ Tech Stack

* **Frontend & Web Framework**: Python (Streamlit)
* **Backend Database**: Snowflake / SQL Database
* **Integrations**: REST APIs / JSON Serialization

---

## 🚀 Key Features

* ✨ **Custom Ingredient Selection**: Multi-select interface for fruit options, base selection, and custom add-ins.
* ✨ **Real-time Order Logging**: Instant order writeback into backend order tracking tables.
* ✨ **Fulfillment Status Dashboard**: Status tracking view for kitchen staff to mark orders as fulfilled.
